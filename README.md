
# Route Business Finder

1. npm install
2. Get free OpenRouteService API key.
3. Replace PUT_OPENROUTESERVICE_KEY_HERE in App.js
4. npm start

Features:
- Select start and end points
- Draw route polyline
- Search shops/restaurants within 500m of route
- Display markers on map

Uses:
- OpenStreetMap
- OpenRouteService
- Overpass API
